# Mainuan GRUB theme
#
# Layout in percentages of the screen, tuned for 1920x1080 and still usable
# from 1024x768. GRUB draws PFF2 fonts as 1-bit bitmaps (no antialiasing), so:
# - the logo + "Mainuan" (Barlow Bold) is a pre-rendered, smooth PNG;
# - menu and system text use DejaVu Sans, whose hinting was made for
#   monochrome rendering and keeps strokes even at 14-18 px.
# Without graphics, GRUB falls back to its text menu and this file is ignored.
